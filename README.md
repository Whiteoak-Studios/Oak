# Oak

Whiteoak Studios' service framework for Roblox — the Knit replacement powering Frontier Zero. Plain-table services, one Blink IDL with exhaustively bound declared remotes, `Init`/`Start` lifecycle, and a fixed inbound policy pipeline (context → rate limit → guards → handler).

Design doc: `KB/Standards/Framework.md` in the [Frontier-Zero](https://github.com/Whiteoak-Studios/Frontier-Zero) repo. Built in Phase 0; published to Wally under the `whiteoak-studios` scope (first publish claims it — run `wally login` once from this directory).
